# Beautytime

A [Storyblok](https://www.storyblok.com/) + [Next.js 16](https://nextjs.org/) project.

## Tech stack

- **Next.js 16** — React framework (App Router)
- **Storyblok** — headless CMS
- **TypeScript**
- **Tailwind CSS**

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
